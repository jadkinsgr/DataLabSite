How to install in Gmail:
1. Press Cmd+A (Mac) or Ctrl+A (Windows) to select everything on this page
2. Press Cmd+C / Ctrl+C to copy
3. In Gmail → Settings → Signature editor, press Cmd+V / Ctrl+V to paste
4. Delete the instruction box text above — only the signature below will appear in emails
